Read the language evidence correctly

Advertised WordPress translations are configuration clues. They do not reveal any account's selected dashboard language, nationality, location, or state affiliation. They do not establish a visitor-facing language switcher. Missing data means unknown. Hosting, agencies, imports, multilingual staff, copied templates, and compromised sites can explain apparent inconsistencies.

en_US is built-in English; en-US is the equivalent homepage language form. An empty raw enum value means the default choice. An advertised additional locale describes translation availability, not a selected dashboard language. Accounts can use different dashboard languages without a visitor-facing language selector.

Collection status: observed means a WordPress REST index or language evidence was obtained. Unknown means those checks did not establish either. Error means collection failed locally or unexpectedly. These are coverage labels, not judgments about the target.
