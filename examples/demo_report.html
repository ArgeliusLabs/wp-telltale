Interpretation

Advertised WordPress translations are configuration clues. They do not reveal any account's selected dashboard language, nationality, location, or state affiliation. They do not establish a visitor-facing language switcher. Missing data means unknown. Hosting, agencies, imports, multilingual staff, copied templates, and compromised sites can explain apparent inconsistencies.

en_US is built-in English; an empty enum value means the default choice. Translation availability can support account interface preferences without a public language switcher. REST enum copies and the login selector often use the same underlying function; they are not independent attribution evidence.
